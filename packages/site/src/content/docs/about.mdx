## The repository

The source of render is on [GitHub](https://github.com/mark1russell7/render). It is a pnpm workspace in the shape of the template of the author. Each package is TypeScript source, and the tests use Vitest and Playwright.

The workflow of GitHub Pages builds this site from the main branch. Before each build, it runs all tests and writes a report, thus [the review](../design/review/) shows the live status of each regression test.

## Writing style

The prose of this site follows ASD-STE100 Simplified Technical English (STE). STE is a style target. ASD does not certify this site. The linter `ste-lint` examines the prose in CI.

## Disclosure

An AI model (Claude, from Anthropic) wrote most of the text and the code of this repository, under the direction of the author. The STEMG of ASD-STE100 asks for this disclosure in its white paper on STE and artificial intelligence (June 2026).
