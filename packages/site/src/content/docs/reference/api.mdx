---
title: The API
description: The exports of each package of render, by layer.
---

Each package exports its API from its root. A package imports only from the layers under it.

## `@mark1russell7/render-optional`

| Export | Purpose |
| --- | --- |
| `Optional<T>`, `none`, `some` | A present value (`Some`) or an absent value (`None`) |
| `isSome`, `isNone`, `map`, `flatMap`, `unwrap`, `fromNullable` | The operations of an optional |

## `@mark1russell7/render-dsl`

| Export | Purpose |
| --- | --- |
| `Expr`, `Lit`, `Ref`, `App` | The IR |
| `lit`, `ref`, `app`, `record`, `chain` | The builders of expressions |
| `isExpr`, `exprEquals`, `MAX_EXPR_DEPTH` | A check of a full tree, the structural equality of two trees, and the limit of the depth |
| `evaluate`, `objectResolver`, `Resolver`, `Ops`, `EvalIssue`, `specialForms` | The interpreter |
| `deps`, `forEachFreeRef`, `mapFreeRefs`, `fnParams` | The analysis of free references |
| `formatExpr`, `parseExpr`, `ParseResult` | The formula language: the text form of the IR |

## `@mark1russell7/render-node`

| Export | Purpose |
| --- | --- |
| `nodeStore({ nodeOps?, ops? })`, `forkStore(store, options?)` | An empty store with its semantics, and an independent copy of a store |
| `addNode`, `setExpr`, `setValue`, `fillMany`, `batch` | The writes of values and expressions |
| `setSlot`, `SlotOptions`, `expandNode`, `removeNode` | The writes of structure. `setSlot` with `own` makes the container the owner of the child |
| `resolveAll` | The repair tool: it rewires and evaluates the full store |
| `getNode`, `readValue`, `readTargets`, `storeResolver`, `toposort` | The reads and the analysis. `readTargets` follows the default structure, and the engine uses the `targets` op |
| `NodeOps`, `defaultOps`, `defaultSplash`, `defaultFlow`, `defaultDeref`, `defaultTargets`, `TargetsFn`, `ReadTargets` | The extension points |
| `Node`, `SplashFn`, `SplashTarget` | A node is read only. A `splash` op writes the value of its target, a `SplashTarget` |
| `valueEquals`, `isPlainObject` | The structural equality of node values |
| `EpochStats`, `MAX_CYCLE_ROUNDS` | The record of an epoch: `evaluated`, `changed`, `cyclic`, `total`. The limit of the rounds of a cycle |

## `@mark1russell7/render-biblo`

| Export | Purpose |
| --- | --- |
| `biblo`, `forkBiblo`, `registerClass`, `registerClasses`, `updateClass`, `renameClass` | The class registry, and an independent copy of a biblo |
| `componentClass`, `extendClass`, `resolveCells`, `resolveMethods` | The classes and their extends chain |
| `registerTrait`, `unregisterTrait`, `resolveTraits`, `classFingerprint`, `primeOf`, `Trait`, `requirementAtoms` | The traits and their prime fingerprints |
| `instantiate`, `destroyInstance`, `moveChild`, `ownerOf` | The instances |
| `classNodeOps` | The class-level reactive semantics |

## `@mark1russell7/render-splay`

| Export | Purpose |
| --- | --- |
| `hydrate`, `hydrateAs`, `splay`, `dehydrate`, `readCells` | The three operations |
| `rehydrate`, `replaceValue` | A new value for an instance: in place, or with a new subtree |
| `splayKit`, `SplayKit`, `SplayOptions`, `RenderCtx`, `DehydrateCtx`, `HydrateCtx` | The kit, the options and the contexts of the methods |
| `viewPolicy`, `ViewPolicy`, `Detail` | The level of detail |
| `SplayCache`, `invalidateSplay` | The memo of splay |
| `standardClasses`, `defaultClassFor`, `exprClassFor` | The standard classes |
| `standardTraits`, `PointTrait`, `LabeledTrait` | The standard traits |
| `standardOps`, `opCategories`, `textOf`, `briefOf` | The standard ops |

## `@mark1russell7/render-viewer`

| Export | Purpose |
| --- | --- |
| `App`, `SESSION_KEY` | The React viewer. Give it a `session` to control its state. With a `storageKey`, it saves its session in the browser. The standalone app and the site use `SESSION_KEY` |
| `KEPT_SUFFIX` | The suffix of the key of a saved session that did not load in full. The App keeps it, and it offers a download |
| `ViewerSession` | The model of the viewer, without React: the actions, undo and redo, `save`, `restore` and `open`, and the level of detail. `open` adds a saved session as one step, thus undo takes it back |
| `SavedSession`, `SavedView`, `Place`, `PlaceRoot`, `RestoreResult` | The JSON form of a session. Each action keeps the place of its instance. `restore` gives `complete`, `partial` or `refused` |
| `viewerKit`, `viewerOps`, `fallbackRender`, `lodFrame` | The view atoms of React, and the disclosure frame |
| `parseFormula`, `Parse`, `Parsed` | The parser of the formula field: a value, an error, or `null` for a draft that is not complete |

## The standalone packages

`@mark1russell7/render-pack` packs rectangles (the layout of the type graph). `@mark1russell7/render-seat` gives reactive path subscriptions over plain values.
