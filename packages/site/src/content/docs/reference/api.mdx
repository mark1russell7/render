---
title: The API
description: The exports of each package of render, by layer.
---

Each package exports its API from its root. A package imports only from the layers under it.

## `@render/optional`

| Export | Purpose |
| --- | --- |
| `Optional<T>`, `none`, `some` | A present value (`Some`) or an absent value (`None`) |
| `isSome`, `isNone`, `map`, `flatMap`, `unwrap`, `fromNullable` | The operations of an optional |

## `@render/dsl`

| Export | Purpose |
| --- | --- |
| `Expr`, `Lit`, `Ref`, `App` | The IR |
| `lit`, `ref`, `app`, `record`, `chain` | The builders of expressions |
| `isExpr` | A check of a full tree |
| `evaluate`, `objectResolver`, `Resolver`, `Ops`, `EvalIssue`, `specialForms` | The interpreter |
| `deps`, `forEachFreeRef`, `mapFreeRefs`, `fnParams` | The analysis of free references |

## `@render/node`

| Export | Purpose |
| --- | --- |
| `nodeStore({ nodeOps?, ops? })` | An empty store with its semantics |
| `addNode`, `setExpr`, `setValue`, `fillMany`, `batch` | The writes of values and expressions |
| `setSlot`, `expandNode`, `removeNode` | The writes of structure |
| `resolveAll` | The repair tool: it rewires and evaluates the full store |
| `getNode`, `readValue`, `readTargets`, `storeResolver`, `toposort` | The reads and the analysis |
| `NodeOps`, `defaultOps`, `defaultSplash`, `defaultFlow`, `defaultDeref` | The extension points |
| `valueEquals`, `isPlainObject` | The structural equality of node values |
| `EpochStats` | The record of an epoch: `evaluated`, `changed`, `cyclic`, `total` |

## `@render/biblo`

| Export | Purpose |
| --- | --- |
| `biblo`, `registerClass`, `registerClasses`, `updateClass` | The class registry |
| `componentClass`, `extendClass`, `resolveCells`, `resolveMethods` | The classes and their extends chain |
| `instantiate`, `destroyInstance`, `ownerOf` | The instances |
| `classNodeOps` | The class-level reactive semantics |

## `@render/splay`

| Export | Purpose |
| --- | --- |
| `hydrate`, `splay`, `dehydrate`, `readCells` | The three operations |
| `splayKit`, `SplayKit`, `RenderCtx`, `DehydrateCtx`, `HydrateCtx` | The kit and the contexts of the methods |
| `SplayCache`, `invalidateSplay` | The memo of splay |
| `standardClasses`, `defaultClassFor`, `exprClassFor` | The standard classes |
| `standardOps`, `opCategories`, `textOf` | The standard ops |

## `@render/viewer`

| Export | Purpose |
| --- | --- |
| `App` | The React viewer. Give it a `session` to control its state |
| `ViewerSession` | The model of the viewer, without React |
| `viewerKit`, `viewerOps`, `fallbackRender` | The view atoms of React |

## The standalone packages

`@render/pack` packs rectangles (the layout of the type graph). `@render/seat` gives reactive path subscriptions over plain values.
